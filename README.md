# apCampaign

apCampaign is a free WordPress newsletter plugin for creating campaigns, managing contact lists, scheduling sends, and honoring unsubscribe requests.

The free edition includes a visual and HTML email editor, reusable templates, preflight checks, delivery tracking, and suppression management. It sends through WordPress mail, so delivery depends on your site's mail configuration and hosting limits. You can configure an independent mail provider or SMTP plugin.

## Install and send

1. Install and activate the plugin on WordPress 6.4 or newer with PHP 7.4 or newer.
2. Set your sender details and physical mailing address in Mailer Settings.
3. Confirm that WordPress mail or your chosen mail provider works.
4. Create a contact list and campaign, review preflight, and send a test before sending to your audience.

Scheduled campaigns depend on WordPress scheduled events. For dependable delivery, confirm that scheduled events run on your site and that your provider permits your sending volume.

## Updates and support

The GitHub release is the free community edition. It does not include the store updater; check this repository for releases and back up your site before updating. A WordPress.org listing is not yet available. The separate [artistpro store download](https://artistprowp.com/apcampaign/) has its own free-update path. Do not install one edition over another without a backup and a plan for its update method.

## Paid features and support

[apCampaign Pro](https://artistprowp.com/apcampaign/) is a separate paid add-on offering additional features and support. The free core remains usable without a purchase. Third-party mail services, including Amazon SES, may charge separately.

For product information and support, visit [artistproWP](https://artistprowp.com/apcampaign/). See [readme.txt](readme.txt) for the plugin's privacy, installation, and release information.
